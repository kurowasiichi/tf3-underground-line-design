Underground View in Line Design

Underground stations and tunnels cannot be seen or picked in the line manager. This mod adds the Underground switch of the construction tools to the line manager.

Features

  • Underground switch - Shown at the top right of the screen while the line manager is open, with the same texts as in the construction tools.
  • Underground key - The underground key of the construction tools (G by default) toggles the switch while the line manager is open.
  • Underground view - The ground turns white and underground stations, stops and tracks are shown. They can be picked when creating a line, adding stops or moving stops and waypoints.
  • Line colors - Lines and vehicles keep their colors in the underground view.
  • Remembered - The underground view keeps its state for the whole game session.

Notes

  • The mod only changes the user interface and has no game script, so it can be added to or removed from existing saves.
  • Other mods that change how the line manager draws the map, or the keys the line manager window accepts, may conflict with this mod.

路線規劃地下檢視

路線管理看不到也點不到地下車站與隧道。這個模組讓路線管理也能用建造工具的地下開關。

功能

  • 地下開關 - 開著路線管理時顯示在畫面右上角，文字與建造工具相同。
  • 地下切換鍵 - 開著路線管理時，建造工具的地下切換鍵（預設 G）也能切換。
  • 地下檢視 - 地面刷白，顯示地下車站、站牌與軌道。新增路線、加站、移動站點與航點時都點得到。
  • 路線顏色 - 地下檢視時路線與車輛照樣上色。
  • 記住狀態 - 地下檢視的狀態在同一次遊戲期間保留。

注意

  • 模組只改介面、沒有遊戲腳本，舊存檔可以隨時加入或移除。
  • 其他改動路線管理地圖繪製方式，或改動路線管理視窗接受哪些按鍵的模組，可能和這個模組衝突。
